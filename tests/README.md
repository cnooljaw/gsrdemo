# 跨进程验收与故障演练

process 是独立 Go 测试 module。默认测试跳过真实进程；从根目录 scripts/process-test.sh 显式构建节点/客户端并启用，--race 同时使用带 race 的节点二进制。

当前切片 A 验收五个真实进程：TS→access Agent→login/online/mole/settlement 的命名 Cluster Call，mole→Agent→TS 的 Push。两个同时活跃的连接验证响应和推送不串连接；空输入拒绝；login 停止后返回明确 unavailable；退出时收回自己启动的全部子进程。测试预留回环临时端口，等待 readiness，释放保留后若端口被争用则失败，不偷偷重选端口。

当前不是登录、玩法、积分或恢复测试。日常包测试留在对应节点/common，不复制 GSR 框架测试。

首轮完整业务验收仍必须跑五进程及至少三客户端：分别登录→同组入座→满员开局→共享目标与竞争命中→局结束→全组待结算→同事务积分到账→查询余额及账本。包含零分及断线成员；另建一组验证组间隔离。保存过的结果重启后必须补齐，未保存不假报到账。

进程/MySQL 演练显式启用、有总超时；等待明确事件而非随机 sleep；强杀及回收只针对测试自己启动的进程。三人斗地主另验手牌隔离、非法操作不改状态及三人同事务结算。

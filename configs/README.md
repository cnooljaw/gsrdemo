# 节点配置

本轮配置是五节点通信演示：access-01、login-01、online-01、mole-01、settlement-01。listen 为节点路由名，共用 nodes 表；不同实例的日志目录独占。路径按进程启动工作目录解释，示例从 gsrdemo 根目录运行。

加载拒绝未知字段、多个 JSON 对象、缺失监听路由与非法地址。Gate 当前为 Plain，仅支持明确的回环/私网开发地址。GSR Cluster.Open 实际绑定 0.0.0.0，nodes 表只声明拨号地址；本轮在可信开发环境使用。跨 access-02 的完整目录行为仍属后续切片。

配置在加载边界完成校验，业务只接收最终值对象。私密配置用被忽略的 *.local.json/*.local.yaml，不在示例中放凭据；数据库字段随真实持久化切片加入。
